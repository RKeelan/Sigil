# Long lines

A paragraph is usually a single source line, however long it is. This one is long enough to wrap several times at any reasonable width: it is numbered once, on its first row, and the rows after it have no number, because the numbers in the gutter count source lines and not rows on the screen. Moving the cursor through it never moves its text, since the whole line shows its syntax for as long as the cursor is anywhere in it, and a line that is already showing its syntax has nothing more to reveal. The same is true of **strong text that runs on for long enough to wrap onto another row of its own, which it does about here, give or take a few words depending on how wide the window is**, and of [a link whose text is long enough to wrap, which is rarer but does happen in writing that links whole phrases](https://example.com/a/rather/long/address/that/nobody/wants/to/read/in/the/middle/of/a/sentence).
